# Khaled Elgafarey Portfolio

Static Arabic portfolio site built with HTML, CSS, and JavaScript. No build step is required.

## Project layout

- `index.html` — portfolio sections and project detail dialogs.
- `dashboard.html` — content management dashboard.
- `css/style.css` — shared site and dashboard styles.
- `js/app.js` — portfolio interactions and content rendering.
- `js/dashboard.js` — dashboard interactions.
- `js/firebase-config.js` — Firebase connection settings.
- `assets/images/` — optimized image assets used by the site, with descriptive English filenames.
- `assets/source-images/` — original uploaded images, preserved for reference and not loaded directly by the site.

Open `index.html` in a browser or publish the project as a static site. The dashboard's shared content storage and Firebase behavior are configured in the existing JavaScript files.
